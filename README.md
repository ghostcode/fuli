# 复利计算器 · Compound Interest Lab

科技风的复利计算工具，基于 **React 18 + Vite + TypeScript** 构建，支持三种计算模式，结果实时可视化。

## ✨ 功能特性

- **期限定投**：输入初始本金（可选）、每期定投金额、年化收益率与期限，计算到期总额、累计本金与累计收益。
- **目标金额**：输入目标金额、年化收益率与期限，反推每期需定投金额。
- **计算年化**：输入初始本金（可选）、每期定投、最终金额与期限，数值反推所需年化收益率；收益为负时给出提示。
- 金额输入框与结果卡片实时显示中文单位（**千 / 万 / 亿**）。
- 复利频率可切换：每月 / 每周 / 每季 / 每年 / 每日。
- 右侧 SVG 增长曲线可视化（青→紫渐变发光描边）。
- 科技风 UI：深色玻璃拟态、霓虹青紫、网格背景。


## 📐 计算原理

采用**期末定投**模型（每期期末投入 `PMT` 并计息）：

- 终值（含初始本金 `PV`）：

  ```
  FV = PV·(1+r)ⁿ + PMT·[(1+r)ⁿ − 1] / r
  ```

  其中 `r` 为每期利率（年化 ÷ 复利频率），`n` 为总期数（年 × 频率）。

- 目标金额反推每期定投：

  ```
  PMT = (FV − PV·(1+r)ⁿ)·r / [(1+r)ⁿ − 1]
  ```

- 计算年化（反推收益率）：无解析解，采用**二分法**数值求解每期利率 `r`，使其满足终值方程等于用户输入的最终金额。

当 `r = 0` 时退化为单利：`FV = PV + PMT·n`。

## 📝 说明

- 所有计算均为税前、未考虑通胀的名义值。
- 「计算年化」模式当结果为负时，表示仅本金与定投之和已超过目标，提示目标设定偏低或投入偏多。
